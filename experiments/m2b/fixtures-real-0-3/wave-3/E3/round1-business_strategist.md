# 決策：B（承接委託，分包兩項關鍵項目，同步建立分包品質管理制度）

## 一、選擇理由：為何是 B 而非 A 或 C

**排除 A 的原因：時程風險與合約罰則直接衝突，屬結構性不相容**
- 認證取得需 9–14 個月，且「時間不完全可控」，但合約要求四個月內簽約、且不接受分批啟動。這意味著簽約當下，本實驗室對這兩項關鍵項目**沒有認證也沒有分包後援**，卻要對委託方承諾全項目交付。
- 合約設有延遲罰則且連續延遲可解約——若把「賭認證準時下來」當作三年期主力業務的核心假設，一旦延遲（機率不低，畢竟過去經驗本就有 9–14 個月的區間跨度），觸發的不是小損失，而是**整份三年委託解約**，同時可能連帶損傷實驗室聲譽，影響既有研究型客戶信任。
- A 本質上是把「不可控的稽核機關時程」當成可承諾給客戶的交期，這是把外部不確定性直接轉嫁成對客戶的違約風險，判斷上不成立。

**排除 C 的原因：在現有資訊下，C 是保守但非唯一安全解，且成本被低估**
- C 迴避了風險，但代價是明確且巨大：三年內不會再有同等規模機會，實驗室維持小量穩定的研究型結構。這是「用已實現的機會成本，換取不確定的風險規避」。
- 題目已明確存在一條路徑（分包）可以在不違反認證範圍要求、不依賴不可控時程的前提下承接委託。若這條路徑本身的風險是可管理的（見下段），選擇 C 就是過度保守，放棄了本可爭取的商業轉型機會。
- C 只有在分包路徑的風險被判定為「不可管理」時，才會變成最優解——這是後面「翻轉條件」要處理的問題，但就目前已知條件而言，尚不構成否決分包路徑的理由。

**B 的核心優勢：用已驗證的外部能力，替換掉不可控的內部時程**
- 分包方已具備該兩項認證，並提供過去三年稽核紀錄——這是**可驗證、可審查的既有能力**，而非賭未來九到十四個月會不會通過稽核。這把最大的不確定性（認證時程）從「內部不可控」轉換成「外部可盡職調查」的風險，性質完全不同。
- 分包吃掉這兩項目大部分利潤，但其餘項目利潤仍可觀——代表商業上仍然值得做，只是毛利結構改變，不是不能承受。

## 二、目前作業與品質結構能否支撐這份承諾？

**結論：目前不能，但差距是「可透過制度建設補齊」的類型，而非結構性不可能。**

需要正視的三個缺口：

1. **品質管理缺口最關鍵**：法規上分包不免責，本實驗室對委託方負全部責任，包含分包方產生的偏差。但目前「沒有管理外部分包品質的制度，也沒有專責的品質稽核人員」。這代表——**如果現在立刻簽約，B 選項在第一天就是不合格的**。B 之所以可行，前提是「同步建立分包品質管理制度」這件事必須在委託開始交付前，至少完成最低可運作版本（例如：分包方結果的抽驗機制、定期稽核排程、異常回饋與矯正流程、責任介面文件化）。這不是可以邊做邊補的事後補救，而是啟動交付前的**必要前置條件**。

2. **人力與產能缺口**：現有技術員人數不足以支撐三班，招募訓練需 6–9 個月。這個缺口不影響「是否簽約」的判斷（因為主要量體項目的產能問題與分包無關，是本實驗室自身量體項目的排班問題），但會直接影響交付初期能否準時達交期，必須在合約的「爬坡期」條款中明確處理（見下段不可妥協條款）。

3. **主持人角色稀釋**：主持人將有相當比例時間投入流程建置與稽核，研究型服務回應速度下降。這是已知且必然發生的**代價**，不是能否支撐的問題，而是需要在決策前明確承認、並可能需要提前與既有研究型客戶溝通期望管理——但這屬於營運後果，不改變 B 是否可行的判斷。

**整體判斷**：現有結構「尚未」支撐這份承諾，但缺口集中在「分包品質管理制度」與「產能爬坡」兩處，且都屬於簽約前到履約初期可以透過明確條款與時間表補齊的類型，而非題目所描述的「不可控」類型（如認證稽核時程）。這是 B 與 A 的本質差異：A 的風險源頭不可控，B 的風險源頭（制度建設、招募排班）雖有挑戰但可控可規劃。

## 三、最可能讓判斷翻轉的條件

以下任一條件成立，會使判斷從 B 翻轉為 C：

1. **分包方的三年稽核紀錄若存在重大或反覆的偏差記錄**（而非題目預設的「良好穩定」），使得本實驗室即便建立品質管理制度，也難以在短時間內把分包風險壓到可承受範圍內——此時分包等於是把不可控風險換了個名字，而非真正降低風險，應轉向 C。

2. **若分包方的產能無法在合約要求的時間內同步承接本委託的量體規模**（題目未明說分包方產能是否足夠支撐委託全部量體需求）——若分包方本身也有產能上限，等於分包路徑一樣有交付風險，此時 B 的可行性基礎不成立。

3. **若品質管理制度的建置時間，經評估後發現無法在委託實際開始交付分包項目結果之前完成**（例如發現需要的稽核人員招募、流程設計、试運行驗證所需時間，實際上與委託的交付時間表衝突）——此時 B 會退化成「先簽約、邊做邊補品質制度」，這與 A 犯的錯誤（用不可控時程賭合約）性質相同，應翻轉為 C。

4. **若委託方對「主承諾機構全責」的認定方式，在實務上會因分包方偏差而導致本實驗室聲譽或既有研究型客戶信任受到不成比例的損傷**（即分包一旦出錯，傷害不僅限於這份委託，還會波及整體業務）——此風險程度需要在盡職調查分包方時特別評估，若證實過高則應轉向 C。

## 四、簽約前最重要的不可妥協條款

1. **分包治理與責任介面條款**：明確約定本實驗室對分包方品質稽核的最低頻率、抽驗比例、異常通報時限，並要求分包方配合稽核，此條款須在合約簽署前即完成初版品質管理制度文件，作為履約附件，而非簽約後才補做的行政程序。

2. **爬坡期與階段性交期條款**：明確約定合約啟動後一段合理爬坡期（對應人力招募與訓練所需的 6–9 個月），在此期間的延遲罰則門檻應與穩態運營期不同，避免在人力尚未到位前就觸發解約條款。

3. **分包方鎖定與備援條款**：與分包方之間簽訂對應年期的服務協議，明確分包方不得片面終止或大幅調整收費，並要求分包方提供產能承諾（避免分包方成為新的交付瓶頸）。

4. **延遲罰則與解約條件的分級處理**：區分「本實驗室自身項目延遲」與「分包項目延遲」的責任歸屬與補救機制，避免分包方單一事件即觸發整體解約，同時保留本實驗室在分包方持續失能時的終止分包、轉換分包方或啟動自行認證的過渡條款。
