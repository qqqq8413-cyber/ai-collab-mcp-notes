# 決策：A（承接企業與保險合約）

## 最重要的理由

三間據點中有兩間的租約將在一年內到期，且續約與否明確綁定「利用率是否改善」。自費客源的成長機制是口碑轉介，且目前集中在另外兩間據點——這是一個**慢速、且地理上不會自然擴散**的成長模式，無法在一年內解決另外三間據點的空檔問題。換言之，B 方案等於讓時間去賭一件過去三個月、半年都沒發生的事（利用率自然改善），而租約到期是硬性時間點，賭輸的代價是實體據點的永久縮減（五間變三間），這比任何合約帶來的品牌風險都更難逆轉。

同時，合約收入穩定可支撐擴編招募，而招募恰好需要一年以上——這代表現在啟動招募與簽約時間點是對齊的：若等到自然利用率回升才決定擴編，會多浪費至少一年的人力缺口。承接合約是把「治療師人力」這個稀缺資源，用低利用率據點與新進人力去填補合約需求，而非動用目前支撐自費口碑的資深人力，理論上兩種業務可以透過人力分流做到有限度共存。

## 最強的反方論點

診所的專業口碑建立在「療程完整、不趕時間」，這是自費業務轉介成長的根本引擎。合約要求標準化療程長度（短於目前平均）、固定到診時段、旺季優先給合約個案——三者疊加，直接衝擊自費客人最在意的等待時間與療程完整度。已知過去有自費客人因等待過久轉往他處且**沒有再回來**，這代表自費客源一旦流失是不可逆的，且流失的正是轉介口碑的源頭客群。若簽約後在旺季集中出現等待時間拉長，可能在極短時間內侵蝕掉需要多年才能建立的口碑資產，而合約本身只有三年保證、到期後是否續約未知，屆時若自費客源已經流失，診所可能陷入「舊模式回不去、新模式沒保障」的兩頭空。此外，治療師對「縮短單次時間是否影響療效」沒有共識，若在沒有內部標準的情況下倉促上線標準化療程，等同讓專業品質風險完全暴露、且無人可為此把關。

## 什麼條件會讓我改變決策

以下條件在現有資訊中未被證實或證偽，需以條件式表述：

- **若**合約可被限定執行於三間低利用率據點、且旺季時段的排擠效應可被證實不會外溢到兩間自費集中據點，則維持 A；**若**合約條款或實務操作要求全診所五間據點統一排班、無法做到據點間隔離，則應轉向 B，因為保護自費核心據點的可行性是 A 方案能否成立的前提。
- **若**內部治療師在建立統一臨床標準後，多數專業判斷認為標準化短療程對本診所主力病症的療效無顯著影響，則 A 的臨床風險可被管理；**若**共識結果偏向「明顯影響療效」，則應轉向 C 或 B，因為犧牲療效等同犧牲診所存在的根本理由。
- **若**合約單次給付扣除標準化後的成本（人力、行政、超時無額外計費的隱性成本）後，證實實際邊際貢獻為負或極低，則 A 的財務理由不成立，應轉向 B。
- **若**自費客人等待時間拉長後，實際流失率遠高於預期、且新進人力擴編速度不足以在一年內填補自費側的服務缺口，則應考慮在合約執行中重新談判排班比例，或若合約方不允許調整，則須重新評估是否於中途退場（雖然合約為三年約，退場可行性未知，僅能條件式提出）。

## 三年內最需建立的內部機制

**排班／營運**：建立「據點與人力分流」排班制度——合約個案優先排入三間低利用率據點與新進治療師名額，兩間自費集中據點於旺季設定自費保留時段上限，避免旺季排擠效應擴散至核心客群；同時設定自費等待時間的監控上限與預警機制。

**臨床品質標準**：在合約上線前，召集治療師建立「標準化療程的最低必要內容」書面規範，並以治療結果指標（如追蹤滿意度、復發率）持續比較標準療程與延長療程的成效差異，形成有共識、可稽核的臨床依據，而非放任內部歧見未解決就上線。

**定價與客源組合**：分別追蹤各據點、各治療師的自費與合約業務邊際貢獻，確保合約低單價量體不會反過來稀釋整體獲利結構；並將合約穩定現金流明確專款用於擴編招募，而非併入一般營運支出，以確保擴編確實發生、且能逐步釋出人力回補自費側。

**量能治理**：設定季度檢核點，同時監控（1）自費客人等待時間與流失率、（2）各據點利用率變化與租約續約進度、（3）合約履約狀況（時段達成率、標準化療程執行狀況）、（4）擴編招募進度是否對齊一年以上的人力到位時程，並預先設定觸發條件（如自費流失率超過特定門檻）以啟動排班比例的重新調整。
