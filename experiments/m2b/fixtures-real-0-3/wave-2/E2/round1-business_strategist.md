# 商業策略與風險分析：投標決策評估

## 一、A / B / C 可行性與風險逐項檢視

**A（獨立投標）核心風險：出席負荷的物理衝突，而非單純「安排」問題**

題目明示公共標案審查「密集且必須本人出席」，同時三件民間案中兩件「合約載明主持建築師須親自到場」，且此四年期承諾與現有案件時間高度重疊。這不是行政調度可以解決的排程問題，而是**單一自然人是否能同時滿足兩套具法律拘束力的親自到場義務**。一旦時段衝突，結果只有兩種：公共審查缺席（可能導致資格喪失或設計核定延宕，在「全有全無、不接受分階段」的規則下代價極高），或私人合約違約（直接衝擊事務所賴以維生的客戶關係與品牌）。

此外，事務所無公共工程實績、也無法在截止日前補齊有經驗的行政人力，代表得標後將在「規則最嚴、犯錯成本最高」的領域用最生的行政能力運作，且賽制規定得標後不得調整團隊——沒有事後補救的空間。

**結論：A 的失敗機率主要來自結構性、不可事後修正的資源缺口，而非執行力問題，風險等級最高。**

**B（共同投標）解決的是「量」的問題，代價是「質」的問題**

共同投標直接解消 A 案中最致命的兩項缺口：出席負荷（分擔審查）與行政能力（對方團隊）。這使事務所得以同時履行私人合約中的到場義務，也讓公共工程的程序風險由有經驗的一方承擔。

但代價精準打在事務所的核心資產上——「主持建築師個人風格是接案主因」。設計主導權共享，意味著最終成果可能不再代表事務所的辨識度；雙方並列名義，且合作對象風格被評為保守，等同於用品牌識別度去交換執行能力。這是**戰略資產與執行能力的交換**，不是單純的成本問題。

**C（不投標）迴避風險，但沒有解決根本瓶頸**

C 保全現有客戶關係與品牌純粹性，且承認需要時間補足行政能力。但要注意：C 並未處理「僅有一位具簽證資格的主持建築師」這個結構性瓶頸——即使兩三年後行政團隊到位，只要仍是同一人獨自簽證，且屆時民間案量若持續累積，同樣的出席衝突可能重演。C 的機會成本是明確且已知的（同規模標案二到三年一次，且本案是「決定事務所能否進入公共市場」的關鍵案），换來的是「不確定」的未來機會與「不完整」的問題解決。

## 二、建議選項：**B**

在題目給定的硬性條件下（法定親自簽證不可替代、全有全無、得標後不可調整團隊、行政人力招募期長於投標期、兩件現有合約已鎖定到場義務），A 的執行風險屬於**結構性不可行**，不是「困難但可承擔」的等級。C 則是放棄本次已經出現、且被明確定義為「決定事務所未來能否進入公共市場」的機會，且未解決單一簽證人瓶頸。

B 是唯一能在滿足現有合約義務、彌補行政與經驗缺口的同時，仍實際取得本次公共工程進場機會的選項。但 B 的可行性完全取決於能否在簽約前，把「設計主導權共享」與「品牌稀釋」的風險，轉化為可書面控制的具體條款——這是本建議成立的前提，而非附帶事項。

## 三、最可能讓判斷翻轉的條件

**翻轉為 A 的條件：**
- 若能證實公共審查會議日程與兩件私人案的到場義務**經逐案比對後實際上不衝突**（而非題目所暗示需要「重新安排」才能勉強兼顧），且
- 行政能力缺口可透過**短期顧問／外部合作方式**（非全職雇用）在截止日前補足，使 A 的兩大致命缺口同時解除。

**翻轉為 C 的條件：**
- 若在條款談判中，對方對「設計主導權」「作品並列名義」的範圍**堅持不做任何限定**（例如要求並列名義延伸至事務所未來所有對外發表、或設計主導權無任何分工切割空間），
- 或事務所自行評估對方「保守風格」的品牌關聯風險，**足以實質侵蝕現有私人案源**（即現有客戶因風格聯想而流失的預期損失，超過取得公共工程進場資格的預期效益），
則應放棄 B，轉向 C。

## 四、簽約前不可妥協條件

**責任分工**
- 設計主導權不得以「共享」這類模糊字眼呈現，須依**設計階段或項目類別**明確切割（例如概念與整體風格方向由事務所主導，技術性合規審查與行政文件由對方主責），避免「共享」在實務上等同於「事務所風格被稀釋」。

**出席義務**
- 書面明定雙方在公共審查會議中的出席分配比例或場次上限，並**明確保障事務所主持建築師對兩件私人案到場義務的優先順位不受影響**。
- 需有對方無法出席時的補位條款，且該條款不得以「盡力配合」等軟性文字呈現，須為**確定性義務**，否則所有負荷會在衝突發生時自動回流到事務所。

**時程**
- 四年期須有明確分階段里程碑與雙方投入時間表，並訂定**對方違約或延遲時的補救與究責機制**——因得標後不得更換團隊，一旦對方掉鏈子，事務所無法透過調整人力止血，唯一防線是合約中的違約救濟條款。

**風險移轉**
- 對方負責部分產生的延誤、缺失或行政疏漏，其法律責任與賠償須由對方承擔，不得因「共同簽證」而自動連帶轉嫁至事務所。
- 「並列名義」**須限定於本案法定文件與官方紀錄範圍內**，不得延伸至事務所未來的行銷、作品集與對外發表；事務所須保留對自身設計貢獻部分**以自身名義單獨呈現**於私人客戶接觸材料的權利——這是保護事務所核心接案資產（個人風格辨識度）的最低限度防線，沒有這條，B 的風險交換就不成立。
