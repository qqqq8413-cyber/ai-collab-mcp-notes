# 情境 fx-03

## 原始任務

我們是一家訂閱制生鮮食材箱服務，剛結束為期 90 天的封閉 Pilot。

現在要決定下一步：

A. 直接對外公開推出，開始付費獲客
B. 再做一輪 Pilot，改用完全陌生的客群
C. 收掉這條產品線

Pilot 的已知事實（所有人看到的是同一份）：

- Pilot 採邀請制，名單來自公司既有熟客與員工推薦。
- 90 天結束時仍在訂閱的比例很高，中途退訂的人數個位數。
- 退訂者給的理由集中在「配送時段不合」，沒有人提到品質或價格。
- 滿意度問卷分數很高，但填答率約六成。
- 客服工單絕大多數與配送有關，與食材本身有關的極少。
- Pilot 期間沒有做過任何付費廣告，也沒有對陌生客群測試過訊息。
- Pilot 客戶的平均訂單金額明顯高於公司既有單次購買客戶。
- 有數位 Pilot 客戶主動介紹朋友加入，但朋友多半也是既有熟客圈。

請決定 A、B 或 C。

請特別處理：

1. 這些事實實際支持什麼、不支持什麼
2. 最關鍵的未知是什麼
3. 資源應該投在哪裡
4. 哪一項假設一旦錯誤最可能讓你改變決策
5. 未來 90 天應如何驗證

不要強迫共識。如果不同觀點之間存在會改變決策的衝突，必須明確保留並處理。

# 情境 fx-01

## 原始任務

我們是一家專做企業內訓的顧問公司，目前所有收入都來自 B2B 客戶（企業採購整套訓練專案）。

正在決定是否推出「公開班」——也就是對個人售票、混班上課的課程。

三個選項：

A. 直接以自有品牌推出公開班，自建報名與行銷
B. 不自建，與既有線上學習平台合作，由平台招生、我們授課並分潤
C. 暫時不做公開班，維持純企業客戶

已知：

- 企業專案客單價高、但成交週期長，且高度依賴幾位資深講師的時間。
- 現有講師的可授課時數已接近上限，短期無法大量增聘同等級講師。
- 過去兩年陸續有個人來信詢問是否能單獨報名，數量不多但持續。
- 公司沒有面向個人的行銷經驗，也沒有報名／金流／客服系統。
- 既有的線上學習平台握有個人客群，但會取得學員名單與定價話語權。
- 部分企業客戶的採購窗口，本身就是過去在別處上過我們公開課的人。
- 公司帳上現金足以支撐一次中等規模的嘗試，但不足以同時投入自建系統與行銷。

請決定 A、B 或 C。

請特別處理：

1. 這個選擇如何影響既有 B2B 收入
2. 講師時間如何配置
3. 品牌與定價的長期影響
4. 哪一項假設一旦錯誤最可能讓你改變決策
5. 未來 90 天應如何驗證

不要強迫共識。如果不同觀點之間存在會改變決策的衝突，必須明確保留並處理。

# 情境 fx-02

## 原始任務

我們是一家社區型動物醫院，目前只有一個院區。

董事會已經同意「兩年內開設第二院區」是正確的成長方向，現在要決定的是執行時程：

A. 今年下半年就開，邊開邊補人
B. 延到明年下半年，先把人力與流程準備好再開
C. 不設時程，等關鍵職缺補齊後再啟動

已知：

- 現有院區的預約已經常態性排到兩週後，飼主等待時間是目前最大的抱怨來源。
- 主治獸醫共三位，其中一位同時負責夜間急診輪值。
- 動物醫院的執業獸醫招募週期長，過去一次招募從開缺到到職平均超過四個月。
- 資深獸醫助理是流程的實際支柱，目前兩位，離職會直接影響看診量。
- 第二院區的物件已經看好，房東願意保留三個月，之後不保證。
- 現有院區的內部流程（掛號、病歷、追蹤）大量依賴口頭默契，沒有寫成文件。
- 公司有足夠資金支付第二院區前一年的租金與裝修，但不足以同時大幅加薪留才。

請決定 A、B 或 C。

請特別處理：

1. 現有院區的服務品質如何不被拖垮
2. 人力與排班如何配置
3. 哪些前置條件是啟動的必要條件
4. 哪一項假設一旦錯誤最可能讓你改變決策
5. 未來 90 天應如何驗證

不要強迫共識。如果不同觀點之間存在會改變決策的衝突，必須明確保留並處理。

請用繁體中文回答。
